# Choose a serving quantity when adding a food to the log

## Description

Serves S3-1 by asking how many servings the student ate before saving the entry.

## Specs

- `ServingQuantitySelector` has − and + buttons that move in half-serving steps from 0.5 to 10, plus quick picks for 0.5×, 1×, 1.5× and 2×. It starts at 1 serving each time it opens.
- The add sheet shows calories, protein, carbs and fat for the chosen quantity. Unknown values show "—" and are never shown as 0, with a note that they won't count toward totals.
- The quantity rules live in `apps/mobile/src/features/daily-log/entries.ts` (`isValidServingQuantity`, `stepServingQuantity`, `scaleNutrition`) with no React imports.
- The stepper is one adjustable control for screen readers, with increment and decrement actions.
