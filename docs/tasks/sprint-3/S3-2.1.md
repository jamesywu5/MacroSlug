# Calculate daily nutrition totals from log entries

## Description

Serves S3-2 by adding a pure function that totals a day's food log entries into calories, protein, carbohydrates, and fat. Showing totals next to goals (S3-2.2), screens, editing and removing entries (S3-4), and fetching entries from the API are out of scope.

## Specs

- `calculateDailyTotals(entries)` in `apps/mobile/src/features/daily-log/totals.ts` takes an array of `LogEntry` and returns `{ entryCount, calories, protein, carbohydrate, fat }`. Each nutrient is `{ amount, missingCount }`.
- A `LogEntry` has `serving_quantity` and per-serving `calories`, `protein`, `carbohydrate`, `fat`, as returned by `GET /api/log-entries`.
- `amount` is the sum of per-serving value × `serving_quantity`, rounded to 1 decimal place.
- A value that is `null`, `undefined`, negative, or not a finite number is unknown. It is left out of `amount`, adds 1 to `missingCount`, and is never treated as 0. A value of exactly `0` is known.
- An empty array returns `entryCount: 0` and, for every nutrient, `amount: 0` and `missingCount: 0`.
- A `serving_quantity` that is not a finite number above 0 throws a `RangeError`.
- The function does not change its input, so calling it again after an entry is added, edited, or removed gives updated totals.

## Requirements

- No new runtime dependencies, and no changes to the API, database, or scraper.
- Tests use `node:test` and run with `tsx --test`. Add a `test:daily-log` script, include it in `npm test`, and exclude `src/features/daily-log/` from Jest like `src/features/preferences/`.
- Existing tests must keep passing.

## Acceptance criteria

1. Each nutrient total equals the sum of per-serving value × `serving_quantity`, and `entryCount` equals the number of entries.
2. Fractional serving quantities work, and each `amount` is rounded to 1 decimal place.
3. An unknown value is left out of `amount` and counted in `missingCount`, while the entry's other nutrients are still totaled.
4. A value of exactly `0` counts as known and does not increase `missingCount`.
5. An empty list returns `entryCount: 0` and `amount: 0` and `missingCount: 0` for all four nutrients.
6. A `serving_quantity` of 0, a negative number, `NaN`, or `Infinity` throws a `RangeError`.
7. The function does not change its input, and recalculating after an entry is added, edited, or removed returns updated totals.
