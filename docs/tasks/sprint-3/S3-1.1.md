# Add an "Add to Log" button to food cards and the food detail view

## Description

Serves S3-1 by letting a student start logging a food from the Menu tab. Each food card gets an "Add to Log" button, and tapping a card opens a new food detail view that has the same button. Both open the serving quantity sheet from S3-1.3.

## Specs

- `FoodCard` takes optional `onPress` (open details) and `onAddToLog` props. The card body and the button are separate controls, so screen readers can reach both.
- New route `apps/mobile/src/app/food/[id].tsx`, shown as a modal. It shows the food's name, hall and meal, nutrition per serving, missing-data warning, and dining hall labels, with an "Add to Log" button pinned to the bottom.
- The detail view finds the food by id in today's menu. While the menu loads it shows a spinner, and if the id isn't on the menu it says so.

## Requirements

- No changes to the API, database, or scraper.
