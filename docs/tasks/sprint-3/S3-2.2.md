# Flag missing nutrition values in daily totals

## Description

Serves S3-2 (plan Task 2) by adding functions that tell a screen which totals are missing data and how to show them, so unknown values are flagged and never shown as zero. Calculating the totals (S3-2.1), screens, and goal comparison are out of scope.

## Specs

- `flagMissingValues(totals)` in `apps/mobile/src/features/daily-log/missing-flags.ts` takes the `DailyTotals` from `calculateDailyTotals` and returns `{ complete, flags }`. `complete` is `true` when there are no flags.
- `flags` has one `{ nutrient, missingCount, message }` for each nutrient whose `missingCount` is above 0, in the order calories, protein, carbohydrate, fat.
- `message` reads "1 food has no protein data" or "3 foods have no protein data". The nutrient words are calorie, protein, carb, and fat.
- `formatTotal(totals, nutrient)` in the same file returns the text for one total: the plain amount (`"1500"`, and `"0"` for a real zero) when nothing is missing, the amount followed by `+` (`"40+"`) when some foods are missing data, and `"—"` when every logged food is missing data.
- Neither function changes its input.

## Requirements

- No new runtime dependencies, and no changes to the API, database, or scraper. Use `DailyTotals` and `Nutrient` from `totals.ts`.
- Tests use `node:test` and are added to the `test:daily-log` script. Existing tests must keep passing.

## Acceptance criteria

1. When no nutrient has missing data, `flagMissingValues` returns `complete: true` and no flags.
2. Only nutrients with missing data get a flag, in the order calories, protein, carbohydrate, fat, and `complete` is `false`.
3. Messages use "food has" for one and "foods have" for several, with the nutrient words calorie, protein, carb, and fat.
4. `formatTotal` returns the plain amount when nothing is missing, including `"0"` for a real zero.
5. `formatTotal` adds `+` when some foods are missing data, and returns `"—"`, never `"0"`, when every logged food is missing data.
6. Neither function changes the totals passed in.
