# S2-3: Nutrition goals input form

## Description

As a student, I want to enter daily nutrition goals so that I can set personal targets for calories and macronutrients.

## Specs

- Add a Nutrition goals page reachable from the Settings page.
- Show four optional daily target fields:
  - Calories in kcal
  - Protein in g
  - Carbohydrates in g
  - Fat in g
- Display a numeric keyboard for calories and decimal-pad keyboards for protein, carbohydrates, and fat.
- Provide Cancel/back and Save goals actions.

## Requirements

- Keep each field's value in local component state as a string.
- Save goals passes a copy of the current values to an `onSave` callback.
- Do not add persistence or complex validation as part of this task.
- Keep the form and focus treatment usable across supported platforms.

## Acceptance criteria

- A student can open Nutrition goals from Settings and see all four labeled fields with their units.
- Each field accepts and displays text in local state using its specified keyboard type.
- Save goals calls `onSave` with the current string values for all four fields.
- Cancel and the back action return to Settings.
- Tests cover the field definitions, initial values, state updates, and Save payload behavior.
